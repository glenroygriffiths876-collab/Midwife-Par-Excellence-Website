GITHUB WEB-UPLOAD READY

1. Extract the ZIP.
2. Upload ALL files in this folder to the ROOT of your GitHub repository.
3. index.html is intentionally under GitHub's 25 MB browser-upload limit.
4. Commit the changes.
5. Wait 1-3 minutes for GitHub Pages to deploy.
6. Open the site in an Incognito/Private tab first to bypass an older cached version.

The main website photos and Simone assistant artwork are embedded directly inside index.html, so there is no assets folder to lose.
