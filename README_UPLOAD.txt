Upload the CONTENTS of this folder to the repository root, not the ZIP itself.
Required root files/folders:
- index.html
- manifest.webmanifest
- sw.js
- favicon.ico
- .nojekyll
- assets/

The assistant portrait and browser-tab favicon are also embedded directly in index.html as a fail-safe.
The files under assets/ are used for the install/PWA icon.
After updating GitHub Pages, hard-refresh once. If an older installed version remains, remove/reinstall it so the new app icon is picked up.
